# BuyTech brand intro: "Eight Months in the Cart"

38 s, 1140 frames at 30 fps, 1920 x 1080. Built in Remotion from the script and motion brief.

- `renders/buytech-intro.mp4`: master render (H.264, CRF 16) with the ElevenLabs voiceover (Charlie)
- `renders/buytech-reel.mp4`: 1080 x 1920 reel for Instagram, TikTok and YouTube Shorts
- `renders/voice-samples/`: the same script line in each ElevenLabs voice available on the current plan
- `renders/stills/`: one still from the midpoint of each scene

## Render

```bash
npm install
npx remotion render BrandIntro out/buytech-intro.mp4 --codec h264 --crf 16
npx remotion render Reel out/buytech-reel.mp4 --codec h264 --crf 16
npx remotion studio            # live preview
```

## Voiceover and music

`public/audio/vo.mp3` is generated by `scripts/make_vo.py`. The whole script is read in one ElevenLabs request so the rhythm flows naturally. The script then uses the API's word timings to cut the read between lines, shortens only long silences inside a line, and places each line on its scene cue. A few takes are generated and the best-fitting one is kept. Line timings are written to `public/audio/vo-timings.json`, which the video reads for music ducking and captions. The API key comes from the environment's network secret for `api.elevenlabs.io` (header `xi-api-key`), so it isn't stored in the repo.

```bash
python3 scripts/make_vo.py                            # Charlie (default), 3 takes
python3 scripts/make_vo.py TX3LPaxmHKxFdv7VOQHJ 4     # another voice id, 4 takes
```

Music: "Positive Optimistic Background Music" by LNPlusMusic (Pixabay #286238). `scripts/make_music.py` cuts it to the video on its 150 BPM bar grid. The full band comes in on the green chat bubble at 15.5 s. One 4-bar phrase is removed at 26.7 s, on a scene cut. The track's final downbeat lands on "BuyTech" and the logo at 34.7 s, and its natural ring-out carries the tagline. In the video it plays at 40% and ducks to 12% under each voiceover line (about 17 dB below the voice), and a gentle cut around 1–4 kHz leaves room for speech. The Pixabay licence allows it in the video but not as a standalone file, so the track is kept out of git: put the original MP3 at `assets/music/lnplusmusic-positive-optimistic-286238.mp3` and run `python3 scripts/make_music.py` before rendering.

The delivered `renders/buytech-intro.mp4` has its audio normalised to -14 LUFS (YouTube's loudness target):

```bash
ffmpeg -i out/buytech-intro.mp4 -c:v copy -af "loudnorm=I=-14:TP=-1.0:LRA=11" -ar 48000 -c:a aac -b:a 192k renders/buytech-intro.mp4
```

Render with `--props='{"captions":true}'` to burn the script in as subtitles.

## Reel (9:16)

`src/Reel.tsx` puts the logo in a header, the story in a 1080 x 1080 stage (the centre square of the landscape canvas), and burned-in captions on a footer band. The header logo is greyscale and the footer ink until the turn at 15.5 s, when both turn green. Scenes that would not fit the square switch layout through `useReel()` (`src/layout.ts`): in scenes 4 and 5 the browser goes on top with the price or USP chips below, and in scene 7 the cards stack in one column. The footer's lower part is left free for the Instagram/TikTok caption overlay.

## Where things live

- `src/scenes/Scene1.tsx` … `Scene7.tsx`: one component per scene, using the brief's absolute frame numbers
- `src/data.ts`: product name and price (from the live product page) and the screenshot coordinates used for the price ring, card highlights and button pulse
- `src/theme.ts`: brand tokens and motion defaults
- `public/screens/`: website screenshots supplied by the client
- `public/fonts/`: Poppins 700/800 and Inter 500 from Google Fonts, stored locally so renders work offline

# Supercheap Interstate Removals: "Who do you trust?"

55 s vertical ad (1080 x 1920, 30 fps) built from the client script and the Supercheap Video Brand guideline (red `#ED1A38`, navy `#242A66`, Poppins, safe zones 220 px top / 380 px bottom / 64 px left / 160 px right).

- `renders/supercheap/supercheap-who-do-you-trust-9x16.mp4`: master (captions burned in, audio at -14 LUFS)
- `renders/supercheap/supercheap-who-do-you-trust-16x9-1080p.mp4`: YouTube HD, 1920 x 1080, same timing and audio
- `renders/supercheap/supercheap-who-do-you-trust.srt`: subtitles for YouTube
- `renders/supercheap/stills/`, `renders/supercheap/stills-16x9/`: one still per scene

```bash
python3 scripts/make_vo.py scripts/vo/supercheap.json   # voiceover (ElevenLabs, Charlie, Australian)
python3 scripts/supercheap_audio.py                     # ticking bed, music cut, finger snap
python3 scripts/supercheap_srt.py                       # .srt
npx remotion render Supercheap out/supercheap.mp4 --codec h264 --crf 16
npx remotion render SupercheapWide out/supercheap-wide.mp4 --codec h264 --crf 16
```

The 16:9 version uses the same scenes; each scene reads the format (`src/supercheap/format.ts`) and lays out text left, visual right. Captions and small text follow the guideline's x 0.6 rule for 16:9; headlines and numbers are a little larger for punch.

- Code: `src/supercheap/` (`brand.ts` tokens and motion, `components.tsx` captions/headlines/logo sting, `problem.tsx` scenes 1-4 on navy, `solution.tsx` scenes 5-12 on white, `drawings.tsx` illustrations).
- Captions: `public/supercheap/captions.json`, one stressed word per phrase in `*stars*`; the video and the .srt both read it.
- Facts to confirm with the client: `src/supercheap/data.ts` (the calculator price is a placeholder until confirmed).
- Music is the same Pixabay track as the BuyTech video, cut so the upbeat section starts on the logo snap; `music.mp3` is kept out of git (licence).
