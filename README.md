# BuyTech brand intro: "Eight Months in the Cart"

38 s, 1140 frames at 30 fps, 1920 x 1080. Built in Remotion from the script and motion brief.

- `renders/buytech-intro.mp4`: master render (H.264, CRF 16) with the ElevenLabs voiceover (Charlie)
- `renders/voice-samples/`: the same script line in each ElevenLabs voice available on the current plan
- `renders/stills/`: one still from the midpoint of each scene

## Render

```bash
npm install
npx remotion render BrandIntro out/buytech-intro.mp4 --codec h264 --crf 16
npx remotion studio            # live preview
```

## Voiceover and music

`public/audio/vo.mp3` is generated by `scripts/make_vo.py`. The whole script is read in one ElevenLabs request so the rhythm flows naturally. The script then uses the API's word timings to cut the read between lines, shortens only long silences inside a line, and places each line on its scene cue. A few takes are generated and the best-fitting one is kept. Line timings are written to `public/audio/vo-timings.json`, which the video reads for music ducking and captions. The API key comes from the environment's network secret for `api.elevenlabs.io` (header `xi-api-key`), so it isn't stored in the repo.

```bash
python3 scripts/make_vo.py                            # Charlie (default), 3 takes
python3 scripts/make_vo.py TX3LPaxmHKxFdv7VOQHJ 4     # another voice id, 4 takes
```

Music: add `public/audio/music.mp3` and re-render. It plays at 70%, ducks to 25% under each voiceover line, and fades out from 36.7 s. Both audio files are picked up automatically. Render with `--props='{"captions":true}'` to burn the script in as subtitles.

## Where things live

- `src/scenes/Scene1.tsx` … `Scene7.tsx`: one component per scene, using the brief's absolute frame numbers
- `src/data.ts`: product name and price (from the live product page) and the screenshot coordinates used for the price ring, card highlights and button pulse
- `src/theme.ts`: brand tokens and motion defaults
- `public/screens/`: website screenshots supplied by the client
- `public/fonts/`: Poppins 700/800 and Inter 500 from Google Fonts, stored locally so renders work offline
